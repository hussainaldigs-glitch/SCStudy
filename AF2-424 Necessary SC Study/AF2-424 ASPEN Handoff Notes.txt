Remaining procedure steps (per "PJM Short Circuit Study Procedure.docx" section 5-9):
  1. Resolve A-02 and A-05 above before touching ASPEN.
  2. Open AF2-424_Necessary_Without.OLR in ASPEN OneLiner.
  3. Hide (not delete) unrelated buses; locate/prepare the Reed / Reed Tap #1 / AF2-424
     region per A-05.
  4. Save this as the real AF2-424_Necessary_Without.OLR, run Network > Set Generator
     Reference Angle, then Check Short Circuit Ratings with Area = 229, OSF =
     PPL_2027.OSF, CSV output on. Save as AF2-424_Necessary_Without.csv.
  5. Copy to AF2-424_Necessary_With.OLR, apply AF2-424_Necessary.chf via
     File > Case Builder (expect 0 errors / 0 warnings -- if not, re-check A-05 wiring
     first). Expand/organize the new buses, set generator reference angle again, run
     Check Short Circuit Ratings the same way, save as AF2-424_Necessary_With.csv.
  6. Use the DWTH add-in (DWTH_v2.xlam, in the repo root) to compare the Without/With
     CSVs and produce AF2-424_Necessary_With_Comparison.xls. Review the duty% column
     for entries >100% with >1% duty delta.
  7. Delete any *.BAK files, update the assumptions doc Status column as items are
     resolved, and the package is complete.
