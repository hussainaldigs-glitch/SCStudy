*** REMAINING ACTION ITEM FOR YOU IN ASPEN -- DO NOT SKIP (A-05) ***
POI is a LINE TAP between "Reed" (0.85 mi) and "Reed Tap #1" (7.01 mi), not a
direct substation connection. You confirmed you'll do this step yourself in ASPEN.
When you open the case:
  1. Open the base case, search for an existing Reed <-> Reed Tap #1 69kV line.
  2. If found, compare its total length to 0.85 + 7.01 = 7.86 mi. If it's close,
     no change needed. If it differs meaningfully, scale the tap-segment
     impedances proportionally to the QP distances (see procedure section 5.2 /
     training ~1:46:00).
  3. Insert the AF2-424_POI bus at the tap point on that line.
  4. If AF2-424 (or AF2-425) already has buses present from a prior study,
     expand and delete them the way AC2-066 was handled in training, then
     apply the change file.
  5. Since this is a joint AF2-424/AF2-425 project (see A-06), also check
     whether the existing POI position in the base case is already registered
     under "AF2-425" instead of "AF2-424" (this happened in the AF1-285/AE2-306
     joint-project precedent, where the POI bus ended up named 'AE2-306_POI'
     even though every other new bus was prefixed 'AF1-285'). If so, rename
     the POI bus in AF2-424_Necessary.chf from 'AF2-424_POI' to 'AF2-425_POI'
     (2 occurrences, in the final [ADD TRANSMISSION LINE] block) before
     applying the change file.

Change file note: AF2-424_Necessary.chf only contains the standard project elements
(bus data, inverter/generator, GSU, collector equivalent, MPT, attachment line from
AF2-424_POI to AF2-424_mn). It does NOT include an extra POI-to-substation zero-impedance

AF2-425_POI, see step 5 above) directly on the Reed-Reed Tap #1 line (same pattern

Remaining procedure steps (per "PJM Short Circuit Study Procedure.docx" section 5-9):
  1. Handle the A-05 tap-point/POI-naming action item above before touching the
     change file (Area/OSF are already confirmed as PPL/229).
  2. Open AF2-424_Necessary_Without.OLR in ASPEN OneLiner.
  3. Hide (not delete) unrelated buses; locate/prepare the Reed / Reed Tap #1 / AF2-424
     region per A-05.
  4. Save this as the real AF2-424_Necessary_Without.OLR, run Network > Set Generator

  5. Copy to AF2-424_Necessary_With.OLR, apply AF2-424_Necessary.chf via

  6. Use the DWTH add-in (DWTH_v2.xlam, in the repo root) to compare the Without/With
     CSVs and produce AF2-424_Necessary_With_Comparison.xls. Review the duty% column
     for entries >100% with >1% duty delta.

     resolved, and the package is complete.
