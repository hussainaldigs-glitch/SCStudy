AF2-424 (Shamrock Solar, joint with AF2-425) - Necessary Short Circuit Study
ASPEN OneLiner Handoff Notes - RERUN for the POI location fix
==========================================================================

WHY THE RERUN
-------------
PJM's base case has AF2-424_POI connected straight to REED TP1 instead of
tapped on the Reed - Reed Tap #1 69 kV line. Anteneh's direction: keep the
stability/PSSE model as is, but for short circuit:
  - Put the POI on the line, 0.85 mi from Reed and 7.01 mi from Reed TP1,
    with each segment's impedance recalculated for its new length.
  - Model the plant as a single aggregated unit. The POI goes under AF2-424
    and the facility under AF2-425.

The previous With/Without CSVs and the comparison .xls are superseded. Both
the POI location and PJM's old AF2-425 plant model affected them. The first
With case had the new plant AND PJM's old AF2-425 plant in it at the same
time. Rebuild both cases starting from the Without case you used for the
first run, or from PJM's generic base case (see Step 1.1).


FILES FOR THE RERUN (all in this folder)
-------------------------------------
  AF2-424_Necessary_POI-Update.chf    Moves the POI onto the line (Without case).
  AF2-424_Necessary.chf               The plant, facility under AF2-425 (With case).
  AF2-424_Necessary_calculation.xlsx  Project Name (B2) = AF2-425, typed in.
                                      POI Bus Name (D2) = AF2-424_POI, typed in.
                                      Nothing else changed. Column K matches
                                      the change file line for line.
  PPL_2027.OSF                        Unchanged.
  Assumptions doc                     Unchanged (No Assumptions).

Unchanged inputs: TO/Area PPL/229, Ungrounded Wye GSU low side, and the QP
table value for the MPT zero-sequence impedance (not the FAT value).

STEP 1 - WITHOUT CASE
---------------------
  1. Open the Without case and keep a copy of it in case you need to
     start over. Use either:
       - the AF2-424_Necessary_Without.OLR you used for the first run.
         You already removed the old AF2-424 plant from it, so skip
         step 2.
       - PJM's generic base case, XXXXXX_Necessary_AsBuilt_Without.OLR
         (the AF2-424_Necessary_Without.OLR copy in the repo is this
         same file).
  2. Generic base case only: delete the old AF2-424 plant from AF2-424_mn
     back, the same way you did for the first run:
       AF2-424_mn, AF2-424_ter, AF2-424_inxc, AF2-424_inx and
       AF2-424_inv, plus their transformers, generator, the col eqv line
       and the 0.01 mi lead line to AF2-424_POI.
     Keep the AF2-424_POI bus. Then search the buses for "AF2-424". Only
     AF2-424_POI should come up.
  3. Delete the old AF2-425 plant from AF2-425_mn back, with "Delete all
     inside region" (answer No to hidden buses and No to annotations):
       AF2-425_mn (961341), AF2-425_inxc, AF2-425_ter, AF2-425_inx and
       AF2-425_inv, plus their transformers, generator, the col eqv line
       and the lead line to AF2-425_POI.
     KEEP AF2-425_POI outside the region. It's a tap on the FAIR TP2 -
     REED TP2 ckt 2 line, so deleting it would open that line.
     Then search the buses for "AF2-425". Only AF2-425_POI should come
     up, still connected to FAIR TP2 (0.95 mi) and AF2-444_POI (0.114 mi).
     *** This step is required. The new change file adds AF2-425_mn
     (69 kV), _inx and _inxc (34.5 kV), the same names and voltages as
     PJM's old buses, so a leftover gives "Cannot make this change". The
     old AF2-425_inv is 0.645 kV (the new one is 0.63 kV), so a leftover
     there won't error. It would quietly leave a second plant in the
     case, so make sure AF2-425_POI is the only hit. ***
  4. Delete the 'ZBR' line (ckt 1) between REED TP1 and AF2-424_POI.
     Keep the AF2-424_POI bus itself. It should now have nothing
     attached. Don't skip this: the POI update adds a ckt 1 line on that
     same REED TP1 - AF2-424_POI pair, so that add fails if the ZBR is
     still there.
  5. File > Case Builder: apply AF2-424_Necessary_POI-Update.chf, then save
     the TTY log as a .txt.
       Expect 0 errors / 0 warnings: 1 delete and 2 adds, all Success.
       If the delete warns, stop. Otherwise the old 7.86 mi line stays in
       parallel with the new path.
  6. Check the diagram reads:
       REED TP1 --- 7.01 mi --- AF2-424_POI --- 0.85 mi --- REEDNO
  7. Tidy the one-line around Reed / Reed TP1 / AF2-424_POI per the
     procedure (hide unrelated buses, don't delete them). Save as
     AF2-424_Necessary_Without.OLR.
  8. Network > Set Generator Reference Angle.
  9. Check Short Circuit Ratings with Area = 229, OSF = PPL_2027.OSF and CSV
     output on. Save as AF2-424_Necessary_Without.CSV.


STEP 2 - WITH CASE
------------------
  1. Copy the new AF2-424_Necessary_Without.OLR to AF2-424_Necessary_With.OLR.
  2. File > Case Builder: apply AF2-424_Necessary.chf, then save the TTY log.
       Expect 0 errors / 0 warnings. "Cannot make this change" means part of
       the old AF2-425 plant is still in the case. Go back to Step 1.3.
  3. Expand and organize the new buses:
       AF2-424_POI --- lead line (0.02 mi) --- AF2-425_mn --- MPT ---
       AF2-425_inxc --- col eqv --- AF2-425_inx --- GSU --- AF2-425_inv
       (generator)
  4. Network > Set Generator Reference Angle.
  5. Check Short Circuit Ratings the same way (Area 229, PPL_2027.OSF, CSV
     on). Save as AF2-424_Necessary_With.CSV.


STEP 3 - COMPARISON AND WRAP-UP
-------------------------------
  1. Use the DWTH add-in (DWTH_v2.xlam in the repo root) to compare the
     Without/With CSVs. The output is AF2-424_Necessary_With _Comparison.xls.
  2. Review the duty % column for anything over 100% with more than a 1%
     change.
  3. Delete any *.BAK files. The package is complete.
